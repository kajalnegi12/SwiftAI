# SwiftAI 🚀

SwiftAI is a ChatGPT-inspired AI assistant built using the MERN stack, Gemini API, and ImageKit.

## Features

- 🤖 AI-powered conversations using Gemini API
- 💬 Chat history management
- 🎨 Image generation support
- 📱 Responsive design
- 🌙 Dark mode
- 💳 Credit-based usage system
- 📦 Subscription plans
- 🖼️ Community image gallery
- ☁️ Image storage and optimization with ImageKit

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs & Services
- Gemini API
- ImageKit

### Deployment
- Vercel
